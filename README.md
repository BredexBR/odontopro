# OdontoPro

Sistema SaaS para gestão de clínicas odontológicas.

---

## 🚀 Funcionalidades

- Autenticação com Google
- Cadastro de pacientes
- Agendamento de consultas
- Painel administrativo
- Gestão de usuários
